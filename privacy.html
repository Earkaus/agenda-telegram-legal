Política de privacidad

Última actualización: 4 de octubre de 2026.

Agenda Telegram es una aplicación de uso personal. Esta política explica qué datos de Google usa y qué hace con ellos.

Datos a los que accede

  • Google Calendar: eventos del calendario del propietario, para consultarlos y, cuando él lo confirma, crearlos o modificarlos.
  • Gmail (solo lectura): mensajes del propietario, únicamente para generar resúmenes bajo su petición.
  • Google Drive (permiso drive.file): solo los archivos que la propia aplicación crea, es decir, copias de seguridad en la carpeta «Respaldo agenda personal».

Cómo se usan

Los datos se usan únicamente para dar las funciones descritas al propietario de la cuenta. Para redactar resúmenes y respuestas, fragmentos de esos datos se envían al servicio de inteligencia artificial de OpenAI, solo cuando el propietario hace una petición. No se venden, no se usan para publicidad, no se comparten con terceros distintos de OpenAI para ese fin y no se entrenan modelos con ellos.

El uso que la aplicación hace de la información recibida de las API de Google se ajusta a la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Dónde se guardan

La memoria y las preferencias se guardan en una base de datos privada en el equipo o servidor del propietario. Las copias de seguridad se guardan localmente y en la carpeta de Drive del propio propietario. Las credenciales de acceso se almacenan con permisos restringidos y no se publican.

Retención y eliminación

Las copias de seguridad se conservan 7 días y 4 semanas. El propietario puede revocar el acceso en cualquier momento desde su cuenta de Google (myaccount.google.com/permissions) y borrar la carpeta de respaldo en Drive.
